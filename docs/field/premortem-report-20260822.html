Premortem · retrospectiva prospectiva

Han pasado 6 meses. ArkGate 4.6.5 ha fallado.

El plan era un firewall de escritura de arquitectura más un coach: un config, un check, un doctor. El éxito era adopción retenida con arkgate-check --strict-merge como status GitHub required. Z09 / RB-11 sigue parked. La cohorte no está enrolada. Esto ya está muerto. Lo que sigue es por qué.

1. El fallo más probable

Teatro de instalación, cero enforcement

Los equipos instalan npm, hooks y skills. GitHub Free no puede exigir el status. Cursor hosted, Codex incompleto y OpenCode bypasean el write path. Doctor ya escribe present-but-not-required y configured-not-fired. Nadie lo trata como no-adopción. A los 90 días no hay reloj Z09 que arrancar: writes observed × enforcement strength → 0.

2. El fallo más peligroso

Un false-green público

El único foso declarado es la honestidad. Propia.homes ya mostró merge verde con policy nueva en UI. Un goal.met con análisis parcial, o ENFORCE leído como “el árbol es bueno”, y un senior publica el JSON. Después de eso no hay parche de voz que recupere el claim “false done is forbidden”.

3. El supuesto oculto

Que doctor honesto + install = adopción retenida

El producto trata “dijimos la verdad en JSON” como si eso convirtiera el status en required, nombrara stewards y mantuviera vivo el contrato. Cerrar Z01–Z08 y Z10 mientras Z09 sigue parked es el síntoma: la ingeniería de honesty sustituye a la prueba de campo. Un humano no puede ser a la vez tren de release, claim gate, matriz de 6 hosts y enrolador de 8 adopters externos.

4. El plan revisado
  1. Redefinir “adoptado” esta semana: D0 = prueba de status GitHub required corriendo --strict-merge, o ack escrito advisory-only en .ark/adoption-stance.json. Sin eso, doctor no puede sonar a éxito. Cubre el fallo 1.
  2. Enrolar 3 design partners, no 8 installs de teatro: usar docs/field/cohort-retention-checklist.md. Si no hay 3 con required-status, el producto no tiene campo. Dejar de shippear parches de honesty como sustituto de Z09. Cubre fallos 1 y 6.
  3. Cerrar el agujero Propia para código nuevo: design-delta (o equivalente) on para archivos creados en el candidato dentro de --strict-merge, o cambiar el copy de ENFORCE para que nunca implique forma de código nuevo. Fixture packed TS7 + aliases: goal.met prohibido si completeness !== complete. Cubre el fallo 2.
  4. Congelar el coach 30 días: cero deepen de explore/compass/skills. ROADMAP doing = salud de adapters o recorte de sustantivos en start+doctor (≤12). Cubre fallos 3 y 8.
  5. Cortar hosts o añadir operador: dejar de perseguir OpenCode/hosted Codex/Cursor untrusted como si fueran hard. Nombrar a una segunda persona que pueda publicar, o cadence quincenal máximo. Cubre fallos 4 y 5.
  6. Stewards o Adapt: stewards[] vacío 30 días post-adopt no puede leerse como ENFORCE sano. T4/T5 y baseline-grow exigen --contract-session. Z09 no cuenta wallpaper. Cubre el fallo 7.
5. Lista de verificación pre-lanzamiento
  1. Inventario de árboles de campo conocidos: status required vs present-but-not-required. Si required = 0, no hay adopción que medir (fallo 1 / 6).
  2. Correr un consumidor packed con aliases: afirmar que ningún adapter emite goal.met: true cuando el análisis no es complete (fallo 2).
  3. Contar sustantivos de producto en la primera salida humana de ark start + primer doctor. Recortar hasta ≤12 (fallo 3).
  4. Doctor: stewards[] vacío post-adopt no se muestra como ENFORCE “healthy finished” (fallo 7).
  5. Nombrar un segundo publisher o fijar cadence ≤1 release / 14 días. Prohibir tres latest en 36 h (fallo 5 / 4).

Tarjetas de fallo · 8 agentes en paralelo

1. Teatro de instalación

Probabilidad
Daño

4.6.5 midió adopción por npm i + hooks. Tres “adopters” en GitHub Free: el job corre, branch protection no exige el contexto. Cursor hosted / Codex incompleto / OpenCode / humanos nunca tocan el hook. A los 90 días el checklist Z09 está vacío. Wallpaper.

Supuesto: instalar npm + hooks convertiría, por inercia, el check en status required.
  • Crece present-but-not-required; required = 0.
  • Hook configured-not-fired o 0 denegaciones PreToolUse en 14 días.

2. False-green público

Probabilidad
Daño

Z09 parked. Un Next packed TS7 pierde el fallback; --plan dice goal.met con análisis parcial. Strict-merge limpia edges; design-delta opt-in no está en CI. Entran can* en UI. Un staff publica: “dijo ENFORCE, el árbol era basura.”

Supuesto: slices de ingeniería + copy de honesty = veredicto de campo, aunque design-delta sea opt-in.
  • Strict-merge 0 y, en el mismo SHA, residual de diseño en paths tocados, o goal.met con completeness ≠ complete.
  • Z09 parked y cohort = 0 mientras se vende “false done is forbidden”.

3. Impuesto de complejidad

Probabilidad
Daño

El “un minuto” de start nombra cinco puertas, dos planos, parlamento y compass. El senior de 4.3 se ahoga en 4.6.x. ROADMAP prohibió nombres nuevos y profundizó los 13. El funnel muere en la puerta. Quien llega a strict-merge ya tenía arquitecto interno.

Supuesto: agrupar 13 skills en cinco puertas reduce carga mental sin borrar superficie.
  • % de start --apply que en 14 días no ejecutan la acción #1 del doctor.
  • >12 sustantivos de producto en start + primer doctor.

4. Cinta de adapters de host

Probabilidad
Daño

Claude cambia el matcher; Cursor mueve StrReplace; Codex vuelve a mover apply_patch. Doctor escribe configured-not-fired. Los equipos desinstalan hooks. CI sigue verde. El tren 4.6.3–4.6.4 se vuelve el modelo operativo. Writes observed colapsa.

Supuesto: el schema PreToolUse de seis hosts es estable y un maintainer puede perseguirlo a parches.
  • Caída >30% de writes observed / intentos, con CI verde.
  • >15% de doctors de campo con hook configured-not-fired en dos hosts “hard” a la vez.

5. Cuello del maintainer

Probabilidad
Daño

Tres latest en 36 horas. Cada nota cierra con “Z09 still open”. El reviewer independiente de Z09 no puede ser quien shippea. En octubre otro payload Codex; domingo de 4.6.6/4.6.7. Una semana sin parche y npm latest se pudre. Museo de honesty.

Supuesto: un humano puede ser release + claim gate + matriz de hosts + enrolador, y que “one doing” lo protege.
  • ≥2 patches 4.6.x en ≤48 h y “Z09 still open” en N notas consecutivas (ya N≥15).
  • 100% de tags con un solo autor; 0 reviewer identity preregistrada.

6. Sustitutos good-enough

Probabilidad
Daño

El trial típico elige eslint-plugin-import + AGENTS.md de 40 líneas + tsc required. Cursor Rules y Claude Project instructions ocupan el slot. El wedge solo se siente en PreToolUse hard o merge que bloquea. TypeScript-only, sin org plane. “arkgate / Archgate?” mata el pitch. La categoría no se forma.

Supuesto: el wedge se vuelve visible antes de la quemadura, y hay quemaduras suficientes para pagar el learning cost.
  • Conversión D14 de start → Action required <15%.
  • 0/8 consentidos a 90 días post-4.6.5, o D30 required-CI <75%.

7. Decaimiento del contrato

Probabilidad
Daño

Adopt congela 47 cortes. stewards[] vacío = sin team lock. Humanos editan fuera del hook. Un PR mezcla config y producto, firma T4, abre baseline (T5). Luz Enforce. A los 6 meses el contrato describe lo que el último agente escribió. Z09 ingenuo cuenta el cadáver.

Supuesto: Enforce + paquete + required-status prueban un contrato vivo, cuando el parlamento es opt-in.
  • stewards[] vacío ≥30 días post-adopt con stewardNudge emitido.
  • Δ neto >0 de claves de baseline o acks T4 sin --contract-session.

8. El coach se comió el gate

Probabilidad
Daño

IC → DC → PL → SK: el doctor post-green apunta a explore, dual-plan B, extraction cards. El agente mapea 12 archivos. Autopilot aplica A vacío. El senior que vino por dientes ve curriculum. El freeze de nombres se cumplió. El valor primer término —writes observed— no.

Supuesto: se puede inflar el coach sin mover writes observed, porque el contrato sigue decidiendo validez.
  • Invocaciones /ark-explore ÷ writes PreToolUse > 1 por sesión.
  • Sesiones post-green que terminan en plan B sin apply; churn de seniors que citan “liturgia”.
