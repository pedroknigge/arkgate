# ArkGate 4.6.6

- **Status:** current
- **Target npm:** `arkgate@4.6.6` (`latest` after publish)
- **Target Git tag:** `v4.6.6`
- **Prior published:** `arkgate@4.6.5`

**Patch** over **4.6.5**. Phase AL corrective honesty (adopted, created-path merge, stewards,
compact doctor) plus a slimmer public docs surface. No required config migration. No new skill
names, sensors, scores, or runtime-package promotion. Does not close Z09. AL05 stays parked.

## What changed

### Adopted is a merge boundary (AL01)

A tree is **adopted** only when a required GitHub status runs `arkgate-check --strict-merge`,
or `.ark/adoption-stance.json` records `stance: "advisory-only"`. Doctor / start / status do
not treat `AGENTS.md` or a workflow file as success. `operatingMode: enforce` stays
contract-fit (`ok` / `goal.met` / `--strict-merge` unchanged).

### Created-path merge (AL02)

`--strict-merge` / `--strict` evaluate `domain-logic-in-ui` for **created** files versus the
Git merge base. Historical residual and a stronger rule in an existing UI file stay green.
Missing base skips (no exit 2). `--fail-on-new-smells --base-ref` remains the full Z10 ratchet.

### Stewards (AL03)

Empty `stewards[]` cannot print Healthy ENFORCE. T4 weakening and T5 `--update-baseline`
require `--contract-session` even with an empty list.

### Compact first run (AL04)

`ark start --help`, start preview, and the first doctor screen stay at **≤12** product nouns.
Default `arkgate-check --doctor` is compact. `--doctor --all` prints Details. Compass and
deep-module coach stay in JSON.

### Docs surface

npm `CHANGELOG.md` keeps Unreleased + 4.6.x. Pre-4.6 lives under `docs/archive/`. Live
`ROADMAP.md` is the current queue.

## Upgrade

npm install -D arkgate@4.6.6
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
