# ArkGate 4.7.4

- **Status:** published
- **npm:** `arkgate@4.7.4` (published) · `@arkgate/runtime@0.1.0-experimental.0` (`experimental`)
- **Git tag:** `v4.7.4`
- **Prior published:** `arkgate@4.7.3`

**Patch** over **4.7.3**. First experimental npm publication of the ArkRun companion.
**No required config migration.** Does not close Z09 / RB-11. Does not close K01.

## What ArkGate is / isn't

- If the AI writes an illegal import, the write is rejected. The same check fails the pull
  request. Not an API Gateway. Not a folder linter. If the check is not required on the PR,
  the rules file is just documentation.
- **Skills never enforce.** The hook, the check, and required CI do.
- **ArkRules** and **ArkRun** extras are off unless you turn them on.
- `@arkgate/runtime` is optional, 0.x, and **not** production durability.

## What changed

| Area | 4.7.4 result |
|------|----------------|
| Companion registry | `@arkgate/runtime@0.1.0-experimental.0` under dist-tag `experimental` (never `latest`) |
| Release workflow | `publish-npm.yml` publishes the companion when that version is unpublished |
| Companion-only | `publish-runtime.yml` (`--runtime-only`) for a first/experimental publish without a new gate version |
| `/ark-runtime` | `npm view @arkgate/runtime dist-tags --json` can resolve; install `@arkgate/runtime@experimental` |

## What did not change

- Layers / ArkRules / ArkRun sensors and merge teeth
- Skill **names** (still 13)
- Binary check; no numeric score; no LLM process verdict
- In-memory stores (reference-only; `K01` parked)
- ADR 0001 product title
- Historical 4.6.2 three-beat line
- Z09 / RB-11 field claims (**still open**)

## Upgrade

```bash
npm install -D arkgate@4.7.4
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
```

Optional ArkRun companion (experimental):

```bash
npm install @arkgate/runtime@experimental
npm view @arkgate/runtime dist-tags --json
```

```bash
mcp-publisher validate server.json
```

## Compatibility and limits

- No `ark.config.json` migration.
- Host write hardness is unchanged from 4.7.3.
- First publish of the scoped companion needs the npm org `arkgate` and, for a new
  package name, `NPM_TOKEN` (OIDC trusted publishing cannot create the package).
