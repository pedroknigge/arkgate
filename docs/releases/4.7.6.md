# ArkGate 4.7.6

- **Status:** prepared
- **npm:** `arkgate@4.7.6` (`latest`)
- **Git tag:** `v4.7.6`
- **Prior published:** `arkgate@4.7.5`

**Patch** over **4.7.5**. Adds production durability to ArkRun (K01).
**No required config migration.** Companion `@arkgate/runtime` published as `0.1.0-experimental.1`.

Closes K01 (in-process commit gaps).

## What changed

- **Optimistic Concurrency Control:** Workflow Engine now uses OCC via version increments to prevent write collisions.
- **Worker Leases:** Storage layer supports `claim()` timeouts to allow concurrent background workers.
- **Transactional DB Handoff:** Engine operations accept a generic `tx` object passed directly into storage adapters (e.g. Postgres).
- **Crash Recovery:** `resume()` rehydrates incomplete sagas for safe continuation without re-running completed steps.

## What did not change

- Layers / ArkRules
- Z09 / RB-11 field claims (**still open**)

## Upgrade

```bash
npm install -D arkgate@4.7.6
npm install @arkgate/runtime@0.1.0-experimental.1
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
```
