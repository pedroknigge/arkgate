# ArkGate 4.8.2

- **Status:** published on npm `latest` (maintainer GitHub Release checklist below)
- **npm:** `arkgate@4.8.2` (`latest`)
- **Git tag:** `v4.8.2`
- **Prior published:** `arkgate@4.8.1`

**Patch** over **4.8.1**. Frozen 13 skills match four-plane honesty: ArkOrder on
adopt / place / autopilot; ArkRun `kernelRoots`; kernel import `arkgate/runtime`.
**No required config migration.** Does **not** close `K01` / `Z09`.

## What changed

- **Four planes on existing names:** Layers, ArkRules, ArkRun, and ArkOrder stay
  on the frozen 13 skills. No `/ark-order` / `/ark-run`.
- **ArkOrder doors:** Adopt is session-0 (schema `1.3+`, `planeRoots`,
  `maxXiKeys`). Place hands grind to Autopilot. Autopilot is the grind door.
- **ArkRun roots:** `kernelRoots` is preferred (`compositionRoots` is an alias).
  Kernel import is `arkgate/runtime`. Companion `@arkgate/runtime` stays
  deprecated.
- **Skills never enforce.** The write gate and required CI still do.

## What did not change

- Layers / ArkRules sensors
- Z09 / RB-11 field claims (**still open**)
- `K01` in-process bus commit gaps (**still parked**)
- Skill **names** (still 13)

## Upgrade

```bash
npm install -D arkgate@4.8.2
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
```

No required config migration. Refresh skills after upgrade (`--refresh-skills`)
so the project catalog matches `arkgate@4.8.2`.

```ts
import { createStrictArkKernel } from 'arkgate/runtime';
import { createOrderPlane } from 'arkgate/order';
```
