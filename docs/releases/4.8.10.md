# ArkGate 4.8.10

- **Status:** prepared (tree candidate; npm `latest` remains **4.8.9**)
- **npm:** `arkgate@4.8.10` (not published)
- **Git tag:** `v4.8.10` (not created)
- **Prior published:** `arkgate@4.8.9`

**Patch** over **4.8.9**. Amarilla first-aggregate sensors (A1–A11) plus
reporter feedback: incomplete analysis never looks green; `--sensors` success
is not a validity verdict; `arkgate report` drafts an upstream issue after a
human confirms. **No required config migration.** No `schemaVersion` bump. Does **not** close `K01` / `Z09`. No new skill names.

## What changed

- **Hint budget is not silent green (`HINT01`).** When governed files exceed
  `coverage.maxFiles` (default 400), emit `ARKRULE_HINT_BUDGET_EXHAUSTED` with
  exact hinted/governed counts and per-sensor reviewed N/M of scope.
  `--strict-config` fails if an enforced hint sensor is truncated. No
  `arkrules.hintBudget` key.
- **Same budget, named (`HINT02`).** Schema description, configuration docs,
  and diagnostics say `coverage.maxFiles` also bounds structural-hint preload
  for `orchestration-only`, `thin-adapter`, and `writes-via-aggregate`.
- **`--update-baseline` does not rewrite CI YAML (`YAML01`).** GitHub rewrite
  touches only `ark-check` / `arkgate-check` invocation lines. It does not
  append `--baseline` to `concurrency.group` or job-id lines. Writes outside
  the three law files are announced.
- **Shape analysis is not first-method-only (`SH01`).** DomainModel class
  sensors find methods with paren-balanced bodies. Remaining truncation is
  reported (`shape analysed until character N`), not silent green.
- **One invariant-word list (`DS01`).** Shared list includes `ensureInvariants`
  / `raise` / `record` / `.push(`. Assignment `=` is distinct from `===` /
  `!==` / `<=` / `>=`. `pendingEvents = []` is idiomatic; events-array `.push(`
  counts as publish. Object literals and multiline params are not public fields.
- **`writes-via-aggregate` IO + callee (`WA01`).** `@/lib/db` (and local
  `…/db`) counts as an IO import without opening tsconfig. Write tokens require
  callee `db` / `tx` / `client` / `prisma` / `drizzle`; `repo.update(` is not a
  write. PersistenceAdapters layer is a driver when resolved-import facts exist.
- **`postgres` and `drizzle-orm/postgres-js` IO imports.** Hint regex matches
  `from 'postgres'` and `from 'drizzle-orm/postgres-js'` (package subpaths),
  lockstep ArkRules and ArkOrder. `require()` matches the same packages.
- **`ARKRULE_SCOPE_EMPTY` is not freezable (`SC01`).** Config diagnostic, not
  code debt — even with `--force`. Documented law-then-product PR sequence. No
  `allowEmptyScope` key.
- **Baseline keys include the sensor (`BK01`).** `ARKRULE_STRUCTURE` freeze
  keys carry sensor id (and symbol when present). A freeze for
  `orchestration-only` does not silence `thin-adapter` or
  `writes-via-aggregate` on the same file. v1 empty-target keys remain
  exact-match only.
- **Intent prefixes only at intent sites (`IR01`).** Checks apply at
  `publish` / `subscribe` / `defineIntent` / `registerHandler`, `intent` /
  `onEvent` / `reactsTo`, publish `metadata.source`. Not every string literal.
  No `kernel.dtypePrefixes`. A kernel DType such as
  `Management.EvmInspection.Data` does not trip
  `LAYER_INTENT_REFERENCE_VIOLATION`.
- **Honest messages (`MSG01`).** Baseline regenerate note lists
  `ark-check --update-baseline --force --contract-session --author <steward>`.
  Doctor concentration looks at `sensor` / `arkruleId`; orchestration-only
  majority is code debt, not “Fixing the contract”. `--help --all` lists
  `--update-baseline` / `--author`. AO11 9-vs-7 is not a bug.
- **`--sensors` success is not a validity verdict.** Contract +
  coverage-evidence only: no TypeScript, no analysis. Stdout says so; `--json`
  stamps `notAVerdict` / `didNotRun` / `partialMode=contract-only`. It does
  not print `Ark check passed`.
- **React `.set()` is not `GENERIC_UPDATE`.** Only `plane` / `orderPlane`
  callees (or a file that constructs `createOrderPlane`) count as ξ mutation.
  `Map` / `URLSearchParams` / `useState` setters stay silent.
- **`--changed` bounds file-local sensors (`IN01`).** File-local structural
  sensors and hint load honor `--changed`. Import-edge, layer, and cycle
  sensors still see the full governed graph. Optional process-local hint cache
  by content hash. Does not claim 170s becomes seconds. No second analysis
  engine.
- **`arkgate report` / `ark report`.** Existing dual bins draft an upstream
  GitHub issue for `pedroknigge/arkgate` (`package.json` `bugs.url`), never the
  consumer repo. Default prints the draft. Create only with `--submit` and
  `--i-confirm-submit` (or TTY `Type submit to send`). `--yes` does not submit.
  Missing or unauthenticated `gh` prints the draft and the exact
  `gh issue create` command, then exits 2. Not `ark-check --report` (HTML). No
  new skill names.

## What did not change

- `ark.config.json` schema and required configuration
- Skill names (still 13)
- Durable stores / atomic outbox (`K01` remains parked)
- Z09 retained-adoption
- Deprecated `@arkgate/runtime` package version or publication state
- No `arkrules.hintBudget`, `allowEmptyScope`, or `kernel.dtypePrefixes` keys

## Upgrade

```bash
npm install -D arkgate@4.8.10
npx arkgate upgrade --json
npx arkgate-check --doctor
```

No required config migration. After install, `--strict-config` fails when an
enforced hint sensor cannot see its scope.
