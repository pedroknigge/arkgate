# ArkGate 4.8.6

- **Status:** published
- **npm:** `arkgate@4.8.6`
- **Git tag:** `v4.8.6`
- **Prior published:** `arkgate@4.8.5`
- **Superseded on `latest` by:** `arkgate@4.8.7`

**Patch** over **4.8.5**. Phase **LV** — ArkOrder valved loop.
**No required config migration.** Does **not** close `K01` / `Z09`.

## What changed

- **Valve.** First `release()` freezes ξ. Later ξ change is `proposeRelease`
  then `apply`. A raw second `release()` of a different ξ fails
  `ARKORDER_UNVALVED_RELEASE` at runtime.
- **σ identity.** `xiHash` is not `sigmaHash`. `refreshSigma` does not mint a
  pattern.
- **Residual.** ingest returns `absorb | escalate_up | hold` bound to `xiHash`.
  Capacity pack is data. Absorb may `send`; escalate_up human may `raises`.
- **Tape.** ArkRun information package `decisionTape`. Not a bus. Not durable.
- **Store.** Injected `ReleaseStore`; in-memory default is **not** durable.

Public sentence: **ArkOrder freezes the pattern through a valve. ArkRun is how
the residual travels.**

## What did not change

- Skill **names** (still 13; no `/ark-order`)
- Durable stores / outbox (`K01` parked)
- Z09 retained-adoption
- Compact starters still leave ArkOrder and ArkRun **off**
- This library’s `ark.config.json` does **not** turn `arkOrder` on

## Upgrade

```bash
npm install -D arkgate@4.8.6
npx arkgate upgrade --json
npx arkgate-check --doctor
```

No required config migration. Copy
[examples/arkorder-billing/](../../examples/arkorder-billing/) and rename the
three keys.
