# ArkGate 4.6.7

- **Status:** published
- **npm:** `arkgate@4.6.7` (`latest`)
- **Git tag:** `v4.6.7`
- **Prior published:** `arkgate@4.6.6`

**Patch** over **4.6.6**. Production-hardening: CODEOWNERS, eval/pack honesty, CLI extracts,
spawn timeouts, and HTML list cap. No required config migration. No new skill names, sensors,
scores, or runtime-package promotion. Does not close Z09.

## What changed

### CODEOWNERS

`.github/CODEOWNERS` lists `@pedroknigge` for `/src/`, `/bin/`, and `/schemas/`. That is the
in-tree review map. GitHub only enforces it when `require_code_owner_reviews` (or a required
approving-review count) is on for `main`.

### Eval and pack honesty

- `eval/comparative` fixture `saas-dashboard/without-ark` value-imports domain from
  presentation so `ark-check` reports one layer violation. Type-only was non-blocking and
  made the nightly oracle go false-green.
- `npm pack --json` may print ANSI before the JSON. The pack reporter strips CSI and parses
  only JSON lines that include `filename`. Empty `[]` / `{}` stay empty.

### CLI extracts and timeouts

Hook payload, package-manager helpers, and check args/config/watch moved into `bin/lib/`
along existing seams. Module-budget maxima were not raised. git/gh `spawnSync` uses an 8s timeout
and treats timeout as failure, not success.

### HTML list cap

Beginner and full showcase violation lists share a cap of 12 and print `+N more (T total)`.
KPI tiles still count the full array.

npm install -D arkgate@4.6.7
