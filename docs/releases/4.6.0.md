# ArkGate 4.6.0

- **Status:** prepared
- **npm:** not yet `latest` (published latest remains **4.5.7** until this train publishes)
- **Target package:** `arkgate@4.6.0`

**Minor** over **4.5.7**. Ships **Understandable Ark**: clearer human language plus shared
Claude/Grok home skills (always-latest additive floor).

No required config migration. **ArkGate** and **ArkRules** stay as product names (optional
plain gloss on first mention). Machine IDs (`ruleId`, MCP tools, JSON fields) stay stable.
Skills stay at 13 names. Compass is still not a score. Soft hosts stay advisory at write
except Cursor’s existing Write/StrReplace pre-write block.

## What ArkGate is / isn't

- **Guardrail + write firewall + coach** — not an autonomous architect.
- **Green imports / `ark-check` pass ≠ finished architecture or good design.**
- **The improvement compass is not a score.**
- **Enforce green ≠ feature done.**
- **Shared agent skills (home)** are the machine floor; **project skills** follow the pin.

## What changed

| Area | 4.6.0 result |
|------|--------------|
| Human language | Doctor / HTML / skills / public docs use common words |
| Brands | ArkGate + ArkRules kept; gloss, don’t rebrand |
| Shared homes | `--claude-home` / `--grok-home` / `--agent-homes`; doctor `agentHomeGaps` |
| JSON | `designWeak` and `ruleId`s unchanged |
| Freezes | No scores, no new skill names, no silent customized overwrite, no home downgrade |

## What did not change

- Write gate / CI semantics for value-layer import rules
- Codex / OpenCode remain warning-only at local write
- Skill **names** (still 13)
- Z09 / RB-11 field claims (**still open**)
- Binary gate; no numeric trust score; no LLM process verdict in package
- No new ArkRules sensors

## Upgrade

```bash
npm install -D arkgate@4.6.0
# after publish: npm install -D arkgate@latest
npx arkgate-check --install-agent-gates --skills-only --force
npx arkgate-check --install-agent-gates --skills-only --agent-homes --force
npx arkgate-check --doctor
```

No `ark.config.json` migration. Dual bins `arkgate*` / `ark*` unchanged.

### Shared homes

1. Project `.claude/skills` (etc.) follow this checkout’s pin.
2. `~/.claude/skills` and `~/.grok/skills` should stay on the newest ArkGate on the machine.
3. An older project must not pull those homes backward.
4. Absent home trees are normal — doctor stays quiet.

## Compatibility and limits

- Human copy changed; agents that parse JSON field names keep working.
- Does not close Z09 / RB-11 retained-adoption claims.
