# ArkGate 4.8.3

- **Status:** published
- **npm:** `arkgate@4.8.3`
- **Git tag:** `v4.8.3`
- **Prior published:** `arkgate@4.8.2`
- **Superseded on `latest` by:** `arkgate@4.8.4`

**Patch** over **4.8.2**. Persistence **writes** in a use-case skip the aggregate.
Closed sensor `writes-via-aggregate` (ADR 0032). ArkOrder **`xiKeys`** names the
slow decisions so a Prisma PATCH of `plan` is a write-path finding, not a return
value the caller can ignore. Advisory default.
**No required config migration.** Does **not** close `K01` / `Z09`.

## What changed

- **The skip:** Application / Feature files that import Prisma, pg, Supabase, …
  and call `.insert` / `.create` / `INSERT INTO` are named. Route the write
  through a Domain aggregate and a persistence adapter.
- **ArkOrder holds the edge:** declare `xiKeys` (plan / protocol / cost-code
  bound). A managed-layer driver write of those keys is `ARKORDER_XI_FIELD_WRITE`.
  Invoices, seats, hours still `ingest`. Changing the plan is `proposeRelease`.
  Copy [examples/arkorder-billing/](../../examples/arkorder-billing/) and rename
  the three keys. Membership (`projectId`) is not a key.
- **Dead sensors live:** `ARKORDER_TOO_MANY_PARAMS` and
  `ARKORDER_INGEST_WRITES_XI` emit from evidence (ADR 0029).
- **Not copied:** no `Externals/`, no `admission.ts`, no `*.adapter.ts` filename
  law. Consumer globs stay the consumer’s. No construction OS.
- **Skills:** `/ark-place` `/ark-adopt` `/ark-contract` teach the skip. Still 13 names.
- **Starters:** Application template + vertical-slice Features ship the
  aggregate rule advisory.

## What did not change

- Layers / ArkRun / ArkOrder sensors
- Z09 / RB-11 field claims (**still open**)
- `K01` in-process bus commit gaps (**still parked**)
- Skill **names** (still 13)

## Upgrade

```bash
npm install -D arkgate@4.8.3
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
```

No required config migration. Existing `arkrules/*.json` stay valid. To opt in
on a brownfield Application layer, add:

```json
{
  "id": "writes-via-aggregate",
  "sensor": "writes-via-aggregate",
  "mode": "advisory"
}
```

To name the slow product decisions (optional, silent when omitted):

```json
{
  "arkOrder": {
    "mode": "advisory",
    "planeRoots": ["src/main.ts"],
    "managedLayers": ["Application"],
    "xiKeys": ["plan", "cycle", "tenancy"]
  }
}
```
