## What ArkGate is / isn't

- If the AI writes an illegal import, the write is rejected. The same check fails the pull
  request. Not an API Gateway. Not a folder linter. If the check is not required on the PR,
  the rules file is just documentation.
- **Skills never enforce.** The hook, the check, and required CI do.
- **ArkRules** and **ArkRun** extras are off unless you turn them on.
