# ArkGate 4.8.1

- **Status:** published
- **npm:** `arkgate@4.8.1`
- **Git tag:** `v4.8.1`
- **Prior published:** `arkgate@4.8.0`
- **Superseded on `latest` by:** `arkgate@4.8.2`

**Patch** over **4.8.0**. ArkRules invariant coverage no longer reports
`never-had-tests` on large trees whose covering tests exist on disk.
**No required config migration.** Does **not** close `K01` / `Z09`.

## What changed

- **Tests first:** `loadInvariantCoverageInputs` walks test roots before
  production facts so `MAX_COVERAGE_FILES` (400) is not spent before a
  covering `describe`/`it` is read.
- **Selective retain:** when `invariantIds` are passed, a test file is kept
  only if it mentions a catalog id. Scanning extra files is cheap; retaining
  them is the budget. Doctor and policy-delta pass the same ids as the
  architecture scan.
- **Honest budget:** if the file cap is hit, `INVARIANT_UNCOVERED` says the
  coverage file budget was exhausted instead of claiming the suite never
  existed.

## What did not change

- Layers / ArkRules sensors
- Z09 / RB-11 field claims (**still open**)
- `K01` in-process bus commit gaps (**still parked**)

## Upgrade

```bash
npm install -D arkgate@4.8.1
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
```
