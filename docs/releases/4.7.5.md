## What ArkGate is / isn't

- When the agent writes a bad import, the write doesn’t land. The same check fails the pull
  request. Not an API Gateway. Not a folder linter. If the check is not required on the PR, the
  config is just documentation.
- **Skills never enforce.** The hook, the check, and required CI do.
- **ArkRules** and **ArkRun** extras are off unless you turn them on.
