# ArkGate 4.8.8

- **Status:** prepared (not published)
- **npm candidate:** `arkgate@4.8.8`
- **npm `latest`:** `arkgate@4.8.7`
- **Planned Git tag:** `v4.8.8`
- **Prior published:** `arkgate@4.8.7`

**Patch** over **4.8.7**. It packages the ArkRun observability dashboard,
bounded inspector monitor facts, ArkOrder fact-vs-conclusion guidance, and the
plain public story. **No required config migration.** No `ark.config.json`
schema bump. Does **not** close `K01` / `Z09`.

## What changed

- **Terminal dashboard.** New `ark-dashboard` / `arkgate-dashboard` bins poll
  the loopback inspector with ANSI output. `ark dashboard` / `arkgate dashboard`
  dispatch to that same executable. It is a developer view, not a gate verdict.
- **Honest inspector hardening.** The snapshot reports durability from the real
  outbox, audit, and workflow store ports. Default `InMemory*` stores are marked
  `memory`; the dashboard never calls an all-memory setup durable.
- **Bounded queue monitors.** Loopback-only `GET /outbox` and `GET /workflows`
  return full counts with sanitized samples capped at 32. Event and workflow
  payloads are not returned. Missing ports say `available: false` instead of
  inventing healthy data.
- **Same safety boundary.** The inspector still binds `127.0.0.1`, refuses
  `NODE_ENV=production`, and lazy-loads HTTP. Built-in stores remain in-memory,
  lose data on restart, and do not supply an outbox or production durability.
- **ArkOrder naming honesty.** Skills and docs ask whether a proposed slow key
  can be recomputed from current data and whether it drives ingest or is derived
  from ingest. `paid` stays derived. This is modeller guidance; the deterministic
  check remains silent on semantic entailment.
- **Plain public opening.** README and the seven canonical opening docs share
  four natural English paragraphs explaining ArkGate, ArkRules, ArkRun, and
  ArkOrder. STAR is only the writing method; no formula heading or labels appear.

## What did not change

- `ark.config.json` schema and required configuration
- ArkOrder runtime sensors or invariants
- Skill names (still 13; no `/ark-order` or dashboard skill)
- Durable stores / atomic outbox (`K01` remains parked)
- Z09 retained-adoption
- Deprecated `@arkgate/runtime` package version or publication state

## Upgrade

```bash
npm install -D arkgate@4.8.8
npx arkgate upgrade --json
npx arkgate-check --doctor
# optional ArkRun developer view
npx ark-dashboard --url http://127.0.0.1:<port>/snapshot
# or: npx ark dashboard --url http://127.0.0.1:<port>/snapshot
```

The dashboard also polls sibling `/outbox` and `/workflows`. `--interval` is
clamped to 200–60000 ms (default 2000).
