# ArkGate 4.8.11

- **Status:** prepared (tree candidate; npm `latest` remains **4.8.10**)
- **npm:** `arkgate@4.8.11` (not published)
- **Git tag:** `v4.8.11` (not created)
- **Prior published:** `arkgate@4.8.10`

**Patch** over **4.8.10**. Nested `--config` with `--root` stays inside that
tree. Library Shape splits `adapterContract` and `agentProjection` so the AI
edits one concern at a time. **No required config migration.** No `schemaVersion` bump.
Does **not** close `K01` / `Z09`. No new skill names.

## What changed

- **Nested `--config` is a file path.** `--root examples/app --config
  examples/app/ark.config.json` no longer treats the nested config as a
  walk-up filename and no longer latches the parent contract, so `include`
  no longer scans the invoker cwd. Basename walk-up remains for
  `ark.config.json`.
- **`adapterContract` Shape split.** Types/schema and finding-ref helpers
  are their own modules. The public facade stays under the god-module floors
  (400 LOC / 12 exports). Callers still import `src/domain/adapterContract.ts`.
  CLI pure helpers follow the DF03 split.
- **`agentProjection` Shape split.** Types/markers, body/meta formatters, and
  merge/stamp are their own modules. The public facade re-exports. Callers still
  import `src/domain/agentProjection.ts`. Generated CLI children stay in
  DomainModel so the facade does not import Tooling.
- **`doctorResidentWarm` ceiling 680ms.** Recalibrated after the
  adapterContract split (~12% headroom). Still far below one-shot doctor.
- **Dev-tree pins.** `browserslist` 4.28.8 and `fast-uri` 3.1.7. Lock/override
  pins, not a consumer API change.

## What did not change

- `ark.config.json` schema and required configuration
- Skill names (still 13)
- Durable stores / atomic outbox (`K01` remains parked)
- Z09 retained-adoption
- Deprecated `@arkgate/runtime` package version or publication state
- No new config keys

## Upgrade

```bash
npm install -D arkgate@4.8.11
npx arkgate upgrade --json
npx arkgate-check --doctor
```

No required config migration.
