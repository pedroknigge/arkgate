# ArkGate 4.8.9

- **Status:** prepared (tree candidate; npm `latest` remains **4.8.8**)
- **npm:** `arkgate@4.8.9` (not published)
- **Git tag:** `v4.8.9` (not created)
- **Prior published:** `arkgate@4.8.8`

**Patch** over **4.8.8**. Field diagnostic honesty from consumer `--doctor` and
upgrade JSON, plus Amarilla ArkOrder findings (`appliesTo`, watchlist vs
`maxXiKeys`, `restore`, default clock, `hashOf`, `.d.ts` honesty, packaged
example URL) and ingest-payload honesty. **No required config migration.** No
`schemaVersion` bump. Does **not** close `K01` / `Z09`. No new skill names.

## What changed

- **Doctor default homedir (`AH01`).** `--doctor` no longer throws
  `TypeError: The "paths[0]" argument must be of type string. Received undefined`
  when `CLAUDE_HOME` / `GROK_HOME` / `ANTIGRAVITY_HOME` are unset.
  `skillsDirFor` defaults `os.homedir()`.
- **Live `peerIsolation` is not a dead rule (`CS01`).** `contract-dead-rule`
  skips `peerIsolation: true` + `allowed: false`. A self-allow stays dead. The
  fix text never tells an agent to delete that wall.
- **Skippable CI is not a missing workflow (`CI01`).** `--strict-merge` /
  `--require-gates` still fail when a job `if:` is not fail-closed, but the error
  is `ci-not-fail-closed` and names the workflow file. Next step: remove the
  skippable `if:`, or write `.ark/adoption-stance.json` `stance: advisory-only`.
  `missing-gates` remains only for files that are actually absent.
- **Blocked upgrade JSON (`UP01`).** `ark upgrade --apply --json` when an asset
  is blocked includes `reasonCode: managed-consent-required` and a digest-bound
  `nextCommand` already carrying `--accept-conflicts`. Apply stays atomic.
- **Identity vs raw hash (`UP01`).** Public assets expose `beforeIdentity` /
  `afterIdentity`. `afterHash` is the SHA-256 of the raw desired bytes;
  `state: current` is content identity. Stamp-only `arkVersion` drift can be
  current with unequal raw hashes.
- **Cross-layer `peerIsolation` docs (`PX01`).** A slice wall on a cross-layer
  edge is a `peerIsolation` rule on that `from`/`to` pair (`allowed: false`).
  Domain files without a slice fail-closed unless listed in `sharedRoots`. No
  new engine mode, key, or skill.
- **Intent references share the import classifier (`INT01`).**
  `LAYER_INTENT_REFERENCE_VIOLATION` passes `fromPath` into the same
  `peerIsolation` decision as imports. Shared-root files (for example `app` /
  `kernel`) do not inherit the slice-wall message. Cross-slice file imports
  still deny.
- **Optional `arkOrder.appliesTo` (`AO10`).** Same glob engine as layers.
  `managedLayers` still required. Empty or absent `appliesTo` keeps today's
  all-files-in-layer emit. A Persistence write outside the globs stays silent.
- **Watchlist vs `maxXiKeys` (`AO11`).** `xiKeys` is a repo-wide watchlist.
  `maxXiKeys` caps one `release()` / `assertXiKeyCap` only (default 7). Eight
  named keys with `maxXiKeys` 7 is valid config. `arkorder-too-many-params`
  fires on `release()` `keyCount`, not on config list length.
- **`restore(release)` (`AO12`).** `OrderPlane.restore` installs a previously
  frozen `Release` (current + version). Hash remains the identity. Not durable.
  Does not close `K01`.
- **Default clock (`AO13`).** `createOrderPlane` default `clocks.now` is Kernel
  `Date.now()` (was `0`). Domain stays clock-free. Callers may still inject.
- **`hashOf` (`AO14`).** Public `arkgate/order` exports `hashOf` (alias of
  `hashReleasePayload`) so a stored `Release.hash` can be verified without
  calling `release()`.
- **`.d.ts` honesty (`AO15`).** Public `dist/order` types no longer say
  declarations-only / no runtime. The module is `createOrderPlane`.
- **Packaged example URL (`AO16`).** Packaged docs point the billing gallery at
  `https://github.com/pedroknigge/arkgate/tree/main/examples/arkorder-billing`.
  The folder is not in the npm tarball; `examples/` is not added to
  `package.json` `files`.
- **Ingest payload honesty.** `classifyIngest` uses `kind` for escalate/allow.
  `ConstraintPack` forbids user predicates. "Second week failing a goal" is a
  domain/projector kind, not a pack function. Capacity already reads numeric
  `payloadKey` vs σ.

## What did not change

- `ark.config.json` schema and required configuration
- Skill names (still 13)
- Durable stores / atomic outbox (`K01` remains parked)
- Z09 retained-adoption
- Deprecated `@arkgate/runtime` package version or publication state

## Upgrade

```bash
npm install -D arkgate@4.8.9
npx arkgate upgrade --json
npx arkgate-check --doctor
```

No required config migration. Optional: declare a cross-layer `peerIsolation`
rule on the `from`/`to` pair that should isolate slices.
