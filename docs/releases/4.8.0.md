# ArkGate 4.8.0

- **Status:** published on npm `latest` (maintainer GitHub Release checklist below)
- **npm:** `arkgate@4.8.0` (`latest`)
- **Git tag:** `v4.8.0`
- **Prior published:** `arkgate@4.7.6`

**Minor** over **4.7.6**. One npm package **`arkgate`**: extras are opt-in by config +
subpath. **ArkOrder** (`arkgate/order`) on schema `1.3`. **ArkRun** kernel is
`arkgate/runtime` in the same tarball. `@arkgate/runtime` is **deprecated**.
**No required config migration** for Layers / ArkRules. Schema `1.2` configs migrate
to `1.3` in memory.

Does **not** close `K01` / `Z09`. In-memory stores and the order plane are not Postgres.

## What changed

- **One product:** `npm install arkgate` then
  `import { createAICodeGate } from 'arkgate'`,
  `import { createStrictArkKernel } from 'arkgate/runtime'`,
  `import { ArkModule } from 'arkgate/nestjs'`,
  `import { createOrderPlane } from 'arkgate/order'`.
  Root export stays the gate (no extra factories).
- **ArkOrder extra (`arkOrder`):** silent when absent. Enforced skip: missing plane,
  Domain import of `arkgate/order`, generic `update` of ξ. Four verbs:
  `release` / `project` / `ingest` / `proposeRelease`. Empty blast and ξ key cap fail closed.
- **Billing gallery:** `examples/arkorder-billing/` (`plan` / `cycle` / `tenancy`).
- **`@arkgate/runtime` deprecated.** Prefer `arkgate/runtime`. Companion leftover stays
  0.x `experimental` for existing pins (`0.1.0-experimental.2` already on that tag).
- **Config schema `1.3`:** additive `arkOrder`. Absence is silent.

## What did not change

- Layers / ArkRules
- Z09 / RB-11 field claims (**still open**)
- `K01` in-process bus commit gaps, atomic outbox handoff, and durable stores (**still parked**)
- Skill **names** (no `/ark-order`)

## Upgrade

```bash
npm install -D arkgate@4.8.0
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor
```

ArkRun / ArkOrder stay off until you add `arkRun` / `arkOrder` to `ark.config.json`.

```ts
import { createStrictArkKernel } from 'arkgate/runtime';
import { createOrderPlane } from 'arkgate/order';
```

Do **not** `npm i @arkgate/runtime` for new work.
