# ArkGate 4.7.1

- **Status:** published
- **npm:** `arkgate@4.7.1` (`latest`)
- **Git tag:** `v4.7.1`
- **Prior published:** `arkgate@4.7.0`

**Patch** over **4.7.0**. One project skill catalog, a visible package version in the
skill picker, no home `/ark-*` duplicates, and ArkRun routed through the existing
13 skill names. **No required config migration.**

Does not close Z09 / RB-11. Does not close K01.

## What ArkGate is / isn't

- **Guardrail + write firewall + coach** — not an autonomous architect, and not an app runtime.
- **Skills never enforce.** The gate, hooks, and required CI do.
- **ArkRun is still an extra** — `/ark-adopt` turns it on, `/ark-runtime` wires the companion,
  `/ark-place` scaffolds new kernel-managed files. There is no `/ark-run`.

## What changed

| Area | 4.7.1 result |
|------|----------------|
| Picker | Installed skills stamp `description` with `arkgate@<version>. ` (YAML `arkVersion:` stays for doctor) |
| Catalog | One project copy: `.agents/skills/<name>/SKILL.md`. Cursor/Codex/Antigravity read it natively |
| Adapters | Claude / Grok / OpenCode get relative links to that catalog. `.cursor/commands/ark-*` is not written |
| Home | `--codex-home` / `--agent-homes` skip when the project catalog exists. `--prune-home-duplicates` removes leftover home `ark-*` only |
| MCP | Home Codex MCP is not rebound when `.codex/config.toml` already exists |
| Doctor | Duplicate home catalog → prune, not `--codex-home --force` |
| Skills | `/ark-contract` leftover routes ArkRun extra edits; same 13 names |

## What did not change

- Layers / ArkRules / ArkRun sensors and merge teeth
- Skill **names** (still 13)
- Binary gate; no numeric score; no LLM process verdict
- Companion `@arkgate/runtime` (not republished by this patch)
- Z09 / RB-11 field claims (**still open**)
- K01 in-process commit gaps (**still parked**)

## Upgrade

```bash
npm install -D arkgate@4.7.1
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --install-agent-gates --skills-only --force
npx arkgate-check --install-agent-gates --skills-only --prune-home-duplicates
npx arkgate-check --doctor
```

Restart Codex / Claude / Cursor / Grok after the skill refresh. The picker description
should start with `arkgate@4.7.1.`. After install, restart/retarget Ark MCP so process
`arkgateVersion` matches the pin.

```bash
mcp-publisher validate server.json
```

## Compatibility and limits

- Codex and Cursor list every skill path they scan. Two copies of the same `name` is a
  host listing issue if home leftovers remain — prune them.
- Adapter symlinks may copy on Windows without symlink privilege; body and version prefix
  still match the canonical catalog.
- `--codex-home` remains for trees that have no project `.agents/skills` yet.

## Security notes

This release does not weaken architecture policy, expand filesystem access, auto-apply
repair output, or broaden hard-write claims. `--prune-home-duplicates` deletes only
frozen `/ark-*` directories under known agent home skill roots, and only when the
project already has `.agents/skills`.
