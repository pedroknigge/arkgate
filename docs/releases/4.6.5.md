# ArkGate 4.6.5

- **Status:** published
- **npm:** `arkgate@4.6.5` (`latest` until 4.6.6 lands)
- **Target Git tag:** `v4.6.5`
- **Prior published:** `arkgate@4.6.4`

**Patch** over **4.6.4**. Adoption, placement, doctor, upgrade, and write-path honesty for
existing Next.js trees and multi-host teams. No required config migration. No new skill names,
sensors, scores, or runtime-package promotion.

## What changed

### Adopt and place (existing trees)

- Adopt proposes **SharedKernel** (types/constants), **CompositionRoot** (wiring), and
  `src/**/domain/**`. A flattened `src/lib/**` bag is not dumped into Application.
- Adopt writes `.ark/golden-pattern.json`. `ark_place` treats it as load-bearing.
- `ark_place` requires `filePath`. Without it the tool fail-closes — it never invents
  `components/*.tsx` or defaults a repository to Presentation.

### Import nextAction and reserved houses

- `LAYER_IMPORT_VIOLATION` nextAction branches by import kind:
  - constants/types/pure → adopt into Domain or SharedKernel
  - kernel/events/bootstrap from Persistence → Persistence must not emit; inject a port or
    move the map to SharedTypes
  - port only when the target is a real use-case
- Layer globs marked `reserved` / `allowEmpty` are future houses, not typos.
  `--strict-config` does not fail on them.

### Parse, lexical, writePath, CI

- `ANALYSIS_PARSE_INCOMPLETE` includes the TypeScript diagnostic (line + message).
  Contract `exclude` paths skip the write hook. Incremental mid-edit parse is normal.
- A hook deny for `LEXICAL_EVIDENCE_INCOMPLETE` does **not** tell the agent to call
  `ark_prepare_change`. Next action is the CLI, or the hook is already the verdict.
- Doctor writes `.ark/ci-merge-boundary.json`: hook configured-not-fired; writePath per host
  (Claude hard vs Cursor soft); CI present-but-not-required; GitHub Free cannot require.
  Read that file instead of `node_modules` dist.
- Hook green is not tree green — scripted edits bypass PreToolUse.

### Upgrade, projection, doctor, graph

- Preview default is **hosts keep**: `--tools` unions with hosts already in the repo.
  Apply installs the bumped package unless `--no-install` is explicit.
- The same projection schema is merged into `AGENTS.md` and `CLAUDE.md`.
- Prefer project `.agents/skills`. Home (`~/.codex/skills`) must not duplicate that catalog.
- `--doctor --json` envelope: `{ schemaVersion: "1.0", envelope: "doctor", ok, doctor }`.
- Doctor #1: ENFORCE + empty plan A and gates installed → Shape, not reinstall gates.
  Distinguishes missing vs stale skills.
- Graph scan threshold scales with included file count (floor 2500, cap 8000).
- `INVARIANT_UNCOVERED` distinguishes never-had-tests vs tests-disappeared.
- CLI-first: identity handshake is optional when the CLI already resolved the root.

## Upgrade

```bash
npm install -D arkgate@4.6.5
npx arkgate upgrade --json
npx arkgate upgrade --apply
npx arkgate-check --doctor --json
```
