# ArkGate 4.8.5

- **Status:** published on npm `latest` (maintainer GitHub Release checklist below)
- **npm:** `arkgate@4.8.5` (`latest`)
- **Git tag:** `v4.8.5`
- **Prior published:** `arkgate@4.8.4`

**Patch** over **4.8.4**. Phase **XP** — ArkOrder × ArkRun — plus Antigravity
skill refresh. **No required config migration.** Does **not** close `K01` /
`Z09`.

## What changed

- **Findable ArkOrder.** [docs/arkorder.md](../arkorder.md) names the APIs two
  adopters redesigned because they could not find them. ArkOrder is a library
  plus static sensors, not a service. Nothing can be “down”.
- **Activation is one shape.** `mode` + `managedLayers` for both extras.
  `planeRoots` vs `kernelRoots` stay distinct factories.
  [ADR 0033](../adr/0033-arkorder-runtime-half-is-arkrun.md): shadow / replay /
  compare are ArkRun and in-memory.
- **Pattern teeth.** Factory options `informationBudget` and `sigmaMaxAgeMs`
  (not `ark.config.json` keys), ξ-must-not-TTL, escalate-to-`human`. Same write
  plane as Layers once the extra is on.
- **Antigravity skills.** `--antigravity-home` writes
  `~/.gemini/config/skills`. Default no-host install includes `antigravity`.

## What did not change

- Skill **names** (still 13)
- Durable stores / outbox (`K01` parked)
- Z09 retained-adoption
- Compact starters still leave ArkOrder and ArkRun **off**

## Upgrade

```bash
npm install -D arkgate@4.8.5
npx arkgate upgrade --json
npx arkgate-check --doctor
```

No required config migration. To name slow keys (optional):

```json
{
  "arkOrder": {
    "mode": "advisory",
    "planeRoots": ["src/main.ts"],
    "managedLayers": ["Application"],
    "xiKeys": ["plan", "cycle", "tenancy"]
  }
}
```

Copy [examples/arkorder-billing/](../../examples/arkorder-billing/) and rename
the three keys.
